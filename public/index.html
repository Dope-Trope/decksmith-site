The idea

Complex software, engineered into simpler control.

DeckSmith builds considered hardware interfaces for the tools that do serious work. The first profile puts the controls you reach for all day onto keys and dials, so the work stays in front of you instead of behind a menu.

The fine print

Built to stay useful.

The model, effort and speed controls drive ChatGPT's composer menu, the only method the app currently exposes. If the model line-up changes, these controls may need an update. Everything else uses direct shortcuts and is designed to stay put.

Tested with the ChatGPT app for macOS on 26 July 2026, and built for a US/ANSI keyboard layout. Stream Deck profiles update by re-download; new versions are published when they are needed.
