Fixing the profile when it stops responding.

Almost every fault with this profile has the same cause and the same fix. Start at the top: it resolves the large majority of cases.

Nothing happens when I press a key

The tell-tale sign is that Open ChatGPT still works while everything else is dead. Folder buttons keep working too, because they never leave the Stream Deck app.

That pattern means macOS has stopped honouring Stream Deck's Accessibility permission. It happens most often straight after a macOS update. Open ChatGPT survives because launching an application needs no permission, while every other control sends a keyboard shortcut, and sending keystrokes does.

The fix

  1. Quit Stream Deck completely. Click its menu bar icon and choose Quit, or press Cmd Q with the window focused.
  2. Open System Settings, then Privacy & Security, then Accessibility.
  3. Find Elgato Stream Deck and switch it off, then on again. Authenticate with Touch ID or your password when asked.
  4. Go back and repeat the same off and on in Input Monitoring.
  5. Reopen Stream Deck and try a key.

Toggle it off and on even if it already looks enabled. This is the part people skip. The switch frequently still reads as on while the permission behind it has gone stale, so the state of the switch tells you nothing. Re-issuing the permission is what actually fixes it.

Still nothing after re-granting

If keys are still dead, something on your Mac is likely holding Secure Input open. While it is active, macOS blocks every synthetic keystroke system-wide, so no app can send shortcuts, not just Stream Deck.

It is usually a password field that still has focus somewhere. Close any open password prompt, unlock dialog, password manager window or login screen, then try a key again. Logging out and back in clears a stuck one.

Restarting your Mac also resolves it, and is worth doing before anything more drastic. There is no need to reinstall the profile: a profile cannot cause this.

Specific keys do nothing, but most work

Eleven of the commands this profile uses ship unassigned in ChatGPT. Until you set them, the keys that use them do nothing, while every key that uses a built-in ChatGPT shortcut works normally. That mixed pattern is the tell.

The download includes chatgpt-keybindings.json, which sets all eleven at once. Copy it over ~/.codex/keybindings.json, then quit and reopen ChatGPT. The app reads that file only at launch, so editing it while ChatGPT is running changes nothing and Settings will keep showing the commands as Unassigned.

To check it took, open Settings, then Keyboard shortcuts, and search for “fast”. If Toggle Fast mode shows a shortcut, they all applied.

KEYBOARD-SHORTCUTS.md in the download lists all eleven if you would rather set them by hand, which takes effect immediately with no restart.

Some keys work, others do not

Shortcuts always go to whichever application is frontmost. If ChatGPT is not the active window, the keys land somewhere else. Press Open ChatGPT first to bring it forward, then use the rest of the page.

The profile is also built for a US or ANSI keyboard layout. On other layouts some punctuation keys sit in different positions, so a few controls may not land where they should even though the rest work normally.

Model and effort keys misfire

The model and reasoning effort controls drive the ChatGPT composer menu, which is the only method the app currently exposes. They depend on the shape of that menu. If the model line-up changes or the menu is reordered, those keys can land on the wrong item.

Everything else in the profile, including approve, decline, plan mode, voice, new chat, fork and all four dials, uses direct shortcuts and is unaffected by menu changes. Updated profiles are published when they are needed.

Requirements

  • Stream Deck +. The profile maps all four dials and the touch strip, so it needs the model that has them.
  • macOS. The shortcuts are macOS shortcuts. There is no Windows version.
  • Stream Deck app 7.5 or later. Earlier versions cannot import the profile correctly.
  • The ChatGPT app for macOS, signed in and installed.
  • A US or ANSI keyboard layout.

Updating the profile

Stream Deck profiles do not update in place. To move to a newer version, download it again from the Elgato Marketplace and import it. Your existing copy can be removed afterwards from the Stream Deck app's profile list.

Re-importing is also the cleanest way to undo any accidental edits to the layout.

Still stuck? Use Contact the Maker on the Elgato Marketplace listing and include your macOS version, your Stream Deck app version and which keys are affected.
